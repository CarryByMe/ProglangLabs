### Задание 6
* Токенизатор  следует правилам: // — до конца строки, /* — до первого */, вложенных нет, а внутри  комментарии не работают. Поэтому в примерах 2, 3 и 5 он закрывает комментарий раньше, чем нужно, и остаток текста превращается в обычные токены (*, /, слова), из которых токенезатор уже не может собрать корректную программу — отсюда ошибка. А примеры 1 и 4 верны: в первом /* */ сидит внутри строки, во втором // съедает всю строку целиком
### Задание 7 
Как видно из правил есть 4 инструкции циклов.
* Первый вид --- цикл с предусловием, который соответствует строке правила:
while ( condition ) statement. Формат записи (по правилу): ключевое слово while, в круглых скобках условие condition, далее инструкция statement.
*   
    ```
    int x = 1;
    while (x < 1000) {
      cout << x;
      x++;
    }
* Второй вид --- цикл с постусловием, который соответствует строке правила:
do statement while ( expression );. Формат записи (по правилу): ключевое слово do, далее инструкция statement, затем ключевое слово while, в круглых скобках выражение expression, завершается точкой с запятой.
*   
    ```
    
  int x = 1;
  do {
    cout << x;
    x++;
  } while (True);

* Второй вид --- цикл с постусловием, который соответствует строке правила:
do statement while ( expression );. Формат записи (по правилу): ключевое слово do, далее инструкция statement, затем ключевое слово while, в круглых скобках выражение expression.
*   
    ```
    
  int x = 1;
  do {
    cout << x;
    x++;
  } while (True);

* Третий вид --- цикл с for, который соответствует строке правила: for ( init-statement conditionOpt ; expressionOpt ) statement;.
 Формат записи (по правилу): ключевое слово for, в круглых скобках  инициализация init-statement, оптицинальное условие condition_opt, точка с запятой, оптицинальное выражение expression_opt, далее инструкция statement.
*   
    ```
    
    for (int i = 0; i < 5; ++i) {
    cout << i + 1;
  }
* Четвертый вид --- цикл по диапазону, который соответствует строке правила: for ( for-range-declaration : for-range-initializer ) statement.
 Формат записи (по правилу): ключевое слово for, в круглых скобках объявление  диапазона for-range-declaration, двоеточие, инициализатор диапазона for-range-initializer, далее инструкция statement.
*   
    ```
    
    for (int x : v) {
    cout << x;
  }
